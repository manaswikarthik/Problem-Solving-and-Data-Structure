# Data Structures & Algorithms – Case Studies

This repository contains three real-world case studies implemented using Python. Each case study consists of five tasks focusing on searching, sorting, hashing, data structures, and algorithmic problem-solving.

---

## Case Study 1: Retail Order Desk

**Scenario:** A retail order management system handles customer orders, requiring efficient searching, sorting, duplicate detection, order processing, and optimization.

### Tasks

1. **Searching Algorithms** – Implement Linear Search and Binary Search to locate orders.
2. **Sorting Algorithms** – Compare Bubble Sort, Merge Sort, and Python's built-in sorting.
3. **Duplicate Detection** – Identify duplicate orders using Hashing.
4. **Stack & Queue** – Implement Stack and Queue for order processing and order history.
5. **Coin Change Problem** – Compare Greedy and Dynamic Programming approaches.

---

## Case Study 2: Retail Bank Transaction Audit

**Scenario:** A bank processes a large number of transactions and requires efficient transaction searching, sorting, duplicate detection, processing, and analysis.

### Tasks

1. **Transaction Search** – Compare Linear Search and Binary Search on transaction IDs.
2. **Transaction Sorting** – Compare Insertion Sort and Merge Sort based on transaction dates.
3. **Duplicate Detection** – Identify duplicate transactions using Hashing.
4. **Stack & Queue** – Implement Stack and Queue for transaction processing.
5. **Min-Max Analysis** – Find minimum and maximum transaction amounts using Brute Force and Divide & Conquer.

---

## Case Study 3: Hospital Appointment Desk

**Scenario:** A hospital manages patient records, appointment schedules, walk-in patients, and doctor availability efficiently.

### Tasks

1. **Patient Search** – Compare Linear Search and Binary Search for patient records.
2. **Appointment Sorting** – Compare Selection Sort and Quick Sort based on urgency and arrival time.
3. **Double Booking Detection** – Detect duplicate appointments using Hashing.
4. **Stack & Queue** – Implement Queue for walk-in patients and Stack for recently viewed patients.
5. **Appointment Scheduling** – Compare Dynamic Programming and Greedy approaches to maximize the number of appointments a doctor can attend.
